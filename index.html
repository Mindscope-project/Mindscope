O projektu

MindScope je studentský projekt zaměřený na psychologii a vědecké poznatky o lidském myšlení, emocích a chování.

Cíl projektu

Cílem je vytvořit webovou aplikaci, která propojí srozumitelná vysvětlení psychologických témat s možností vyhledávat odborné vědecké zdroje.

Plánované funkce

  • Vysvětlení vybraných psychologických témat.
  • Vyhledávání vědeckých studií.
  • Zobrazování autorů, roku vydání a abstraktů.
  • Odkazy na původní odborné zdroje.
  • Možnost filtrování výsledků vyhledávání.

Plán vývoje

Projekt bude postupně rozšiřován během školního roku. Nejprve vznikne základní webová stránka, následně budou přidávána psychologická témata a funkce vyhledávání vědeckých publikací.

Technologie

Plánuji využít HTML, CSS a JavaScript pro tvorbu webu a veřejné API pro získávání údajů o vědeckých publikacích.
